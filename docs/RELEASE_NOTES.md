发布内容包括运行所需的前后端源代码、静态资源、部署配置示例和 AGPL-3.0 许可。`backend/tests`、其他测试/benchmark 脚本及夹具、本机 Trace/数据库、报告样本、运行日志、`.env` 密钥与演示文稿没有进入新仓库的任何可达历史提交。

后续更新应在这个独立仓库中提交经过核对的源代码与文档；不要镜像推送开发仓库的原始历史，以免重新带入已排除的测试文件。
